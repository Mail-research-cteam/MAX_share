# Шаблон чат-бота для UX-исследований

Соберите свой сценарий на примере демо-бота. В одном HTML-файле уже есть чат и визуальный редактор.

## Скачать и отредактировать

1. Откройте на GitHub файл [demo.html](demo.html) и нажмите **Download raw file** (значок скачивания). Сохраните файл на компьютер.
2. Откройте скачанный `demo.html` двойным щелчком. Браузер сразу покажет редактор. Терминал и установка программ не нужны.
3. В **Шапке чата** и **Начале переписки** укажите имя и описание бота. На карточках измените тексты и кнопки. Чтобы добавить шаг, нажмите **Добавить узел**. Для перехода перетащите кружок справа от кнопки на нужную карточку.
4. Нажмите **Перезапустить** и пройдите сценарий в режиме **Превью**.
5. Нажмите **HTML** в верхней панели. Браузер скачает новую копию с вашими правками. Откройте её перед выступлением или отправьте коллеге.

## Опубликовать сценарий по ссылке

Этот способ пригодится, если коллеги или респонденты должны сами пройти сценарий в браузере.

1. Скачайте исходники через **Code → Download ZIP** и распакуйте их. В папке с `package.json` запустите `npm start`. Нужен Node.js 20 или новее.
2. Откройте в браузере адрес **«Бот»**, который напечатает команда. Чтобы открыть редактор на запущенном сайте, добавьте `?edit=1` к адресу страницы. Пример пути — `prototype/index.html?edit=1`.
3. В редакторе выберите **Импорт JSON / HTML**, откройте отредактированный HTML и нажмите **JSON**. Замените `prototype/scenarios/demo.json` скачанным JSON. Для отдельного сценария задайте ему уникальный `id`, назовите файл по этому ID и добавьте запись в `prototype/scenarios/catalog.json`.
4. Выполните `npm run package` и опубликуйте изменения в репозитории своей команды. При размещении через GitHub Pages из корня ветки откройте путь `prototype/index.html?scenario=demo` на адресе опубликованного сайта. Для отдельного сценария подставьте его ID вместо `demo`.

Чтобы добавить отдельный экран, положите его в `prototype/` и укажите путь к нему в узле **Внешняя страница**. Добавьте экран и его ресурсы в `prototype/release-extra.json`, например `{"files":["example.html","assets/example.png"]}`, и выполните `npm run package`.

Лицензия на код пока не выбрана. Условия использования шрифтов и иконок описаны в [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

## Справочник по файлам

| Где лежит | За что отвечает |
| --- | --- |
| [demo.html](demo.html) | Готовый демо-чат с редактором в одном файле. Его можно открыть и редактировать на компьютере. |
| [prototype/index.html](prototype/index.html) | Страница чата на запущенном сайте. Параметр `?edit=1` включает редактор. |
| [prototype/scenarios/demo.json](prototype/scenarios/demo.json) | Данные демо-сценария. Имя бота, сообщения, кнопки и переходы. |
| [prototype/scenarios/catalog.json](prototype/scenarios/catalog.json) | Список сценариев. Первый открывается по умолчанию. |
| [prototype/shared/](prototype/shared/) | Код чата и редактора. `app.js` проигрывает сценарий, `board.js` управляет схемой, `author.js` отвечает за импорт, версии и ZIP, а `standalone.js` собирает автономный HTML. |
| [prototype/assets/](prototype/assets/) | Общий аватар, иконки интерфейса и локальные шрифты. |
| [prototype/release-files.json](prototype/release-files.json) | Список ресурсов для экспорта. Обновляется командой `npm run package`. |
| [tools/](tools/) и [package.json](package.json) | Команды для разработчиков. `npm start` запускает локальный сайт, `npm run package` обновляет экспорт, `npm test` запускает проверки. |
| [docs/board-navigation.md](docs/board-navigation.md) | Справка по навигации на схеме и масштабированию. |
