# Шаблон чат-бота для UX-исследований

Редактор и браузерный прототип чата. В комплекте есть нейтральный пример с двумя ветками. Команды могут адаптировать его под своего бота, собрать сценарий и дать респонденту ссылку.

## Локальный запуск

Установите Node.js 20 или новее. Выполните из корня проекта:

```sh
npm start
```

Оставьте Терминал открытым и откройте в браузере адрес из строки «Бот». По умолчанию там откроется сценарий «Демо» на странице `prototype/index.html`.

Чтобы редактировать сценарий локально, добавьте `?edit=1` к адресу страницы. Пример пути — `prototype/index.html?edit=1`.

Установка npm-пакетов не требуется. При занятом порте запустите `npm start -- --port=8001` и используйте новый адрес из Терминала.

## Как сделать свой сценарий

1. Откройте редактор. В настройках сценария поменяйте имя и статусы бота. В карточке начала отдельно настройте имя и описание.
2. Измените сообщения, кнопки и связи на доске. Пройдите нужные ветки в предпросмотре. Общий аватар лежит в `prototype/assets/demo-avatar.svg`.
3. Скачайте JSON из меню сценария. Черновики сохраняются в текущем браузере. Чтобы разместить один сценарий, замените `prototype/scenarios/demo.json`. Для нескольких сценариев задайте каждому уникальный `id`, используйте его в имени файла и добавьте запись в `prototype/scenarios/catalog.json`.
4. После изменения файлов запустите `npm run package`, чтобы обновить список ресурсов для экспорта. Разместите папку `prototype/` на статическом хостинге. Для выбора сценария в ссылке используйте `index.html?scenario=ваш-id`. Без параметра открывается первый сценарий каталога.

Если сценарию нужен отдельный экран, положите его в `prototype/` и укажите относительный путь, например `example.html`, в карточке «Внешняя страница». Чтобы экран и его ресурсы вошли в экспорт, добавьте их в `prototype/release-extra.json` в виде `{"files":["example.html","assets/example.png"]}` и снова выполните `npm run package`.

## Как передать прототип

- **HTML** открывается двойным щелчком и содержит один сценарий с редактором. После правок скачайте новую копию. Чтобы вернуть изменения в проект, импортируйте полученный HTML через меню и скачайте JSON.
- **ZIP** содержит статический сайт с каталогом и зафиксированной версией выбранного сценария. Распакуйте архив, запустите `node tools/preview.cjs` из его корня и откройте в браузере адрес из строки «Бот» в Терминале.
- **Исходники** подойдут команде, которая хочет вести несколько сценариев или менять оболочку.

`npm test` запускает проверки редактора, сценария, локального сервера и экспорта. [Управление доской](docs/board-navigation.md).

Лицензия на код пока не выбрана владельцем. Условия для шрифтов и иконок перечислены в [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

## Быстрый старт для команды

### 1. Скачать

На GitHub откройте **Code → Download ZIP** и распакуйте архив. Если у вас уже есть Git, можно выполнить `git clone https://github.com/Mail-research-cteam/MAX_share.git`.

### 2. Отредактировать

Откройте редактор по инструкции в разделе [«Локальный запуск»](#локальный-запуск). Настройте имя бота, измените карточки и проверьте обе стороны каждого нового перехода в предпросмотре. Затем скачайте JSON из меню сценария.

### 3. Залить флоу

В репозитории своей команды замените `prototype/scenarios/demo.json` скачанным файлом. Если хотите оставить демо и добавить свой флоу рядом, задайте свой `id` в JSON, назовите файл по этому ID и добавьте его в `catalog.json`. Запустите `npm run package` и закоммитьте JSON вместе с обновлённым списком ресурсов. Отправьте коммит в свой репозиторий.

Если сайт размещается через GitHub Pages из корня ветки, ссылка для респондента будет вида `https://<владелец>.github.io/<репозиторий>/prototype/index.html?scenario=<id>`. Ссылка с `&edit=1` открывает редактор. Чтобы быстро передать редактируемую копию одного флоу без сайта, используйте в редакторе **Скачать HTML**.
